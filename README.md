# EMBER & BITE — Fast Food Web Application

## Fayllar tuzilmasi
- `index.html` — Asosiy mijozlar sayti (Navbar, 5 soniyalik Hero Slider, 20 xil taom har biri 3 xil variantda, Savat, Sevimlilar, 12 viloyat/tumanlar, GPS/Qo'lda manzil).
- `admin.html` — Himoyalangan Admin Panel (Login: `admin`, Parol: `ember2026`).
- `style.css` — Qora neon dizayn, kompyuter, planshet, telefon va Apple Watch uchun moslashuvchan uslublar.
- `script.js` — Barcha mantiqiy qism va Admin panel bilan sinxronizatsiya.

## Netlify va GitHub'ga joylash
1. **Netlify:** Ushbu ZIP faylni Netlify'dagi *Deploy manually* oynasiga to'g'ridan-to'g'ri tashlang (Drag & Drop).
2. **GitHub:** Arxivni ochib, ichidagi fayllarni GitHub repository'ga yuklang.
